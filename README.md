# 🏢 Employee Attrition Prediction & Risk Scoring System

## 📌 Project Overview

The Employee Attrition Prediction & Risk Scoring System is a Machine Learning-based web application developed using Streamlit. The application predicts whether an employee is at risk of leaving the organization and provides an estimated attrition probability based on employee-related features.

This project helps HR departments identify employees with high attrition risk and supports data-driven workforce management.

---

## 🎯 Objectives

- Predict employee attrition using Machine Learning.
- Calculate employee attrition risk.
- Visualize HR analytics through an interactive dashboard.
- Support HR professionals in retention planning.

---

- 📊 Employee Dashboard

## ⚙ Installation

Clone the repository:

```bash
git clone https://github.com/priyadharshinivetrivel/Employee_Attrition_Project.git
```

Move to the project folder:

```bash
cd Employee_Attrition_Project
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
